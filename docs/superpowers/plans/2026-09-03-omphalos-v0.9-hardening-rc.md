# Omphalos v0.9 API Freeze / Hardening / Release Candidate Plan

**Goal:** Freeze and harden the existing Runtime as package candidate `1.0.0rc1` / public API `1.0`, without adding new search behavior.

**Base:** `master@ee490addeaac29efa7831df728950c0cad68f07e`

## Constraints

- `ai_web_research` remains the implementation package.
- `omphalos` is the stable v1-facing facade.
- No new Provider, Search Method, Planner, Stopping, Evidence, Experience, or Evaluation behavior.
- `UNKNOWN != ALLOW`, `Planning != Authorization`, `SearchReceipt != ChainOfThought`, `Learning != SelfAuthorization` remain unchanged.
- Credentials and hidden reasoning must not enter public/release manifests.
- RC is not final v1.0.
- Full-repository test/build/install claims require the GitHub Actions RC gate on the exact PR head.

## Tasks

1. **Public API freeze** — add `omphalos` facade, version constants, deterministic public API manifest, and freeze tests.
2. **Error taxonomy** — add stable public error codes/descriptors, RuntimeErrorRecord conversion, and credential-safe metadata validation.
3. **Package + CLI** — set `1.0.0rc1`, package `src/omphalos`, add `omphalos version`, `api --json`, and offline `doctor --json`.
4. **Release docs** — add Quickstart, API/migration policy, security/credential policy, four reference workflows, and RC notes.
5. **Automated RC gate** — validate package/API versions, manifests, docs, benchmark artifacts, literal secrets, and workflow contract.
6. **Full-checkout CI** — Python 3.11; `pytest -q`; compileall; release gate; `python -m build`; clean wheel install `--no-deps`; CLI version/doctor.
7. **RC manifest** — bind base master, package/API/gate versions, public API SHA-256, v0.8 benchmark SHA-256 values, docs, content-addressed ID, and `rc_not_final_v1=true`.
8. **Final handoff** — single milestone commit, PR without merge, CI verification, deterministic backup ZIP, SHA-256.

## Exit rule

v0.9 is RC-ready only if the exact PR head passes the full-repository GitHub Actions workflow. Promotion to final v1.0 remains a separate Final Release Gate.
