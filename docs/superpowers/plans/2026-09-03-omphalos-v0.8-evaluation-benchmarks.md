# Omphalos v0.8 Evaluation / Benchmark Suite Implementation Plan

**Goal:** Build a deterministic, paired-case, machine-readable evaluation harness and a clearly labeled synthetic reference suite for Provider substitution, Method diversity, adaptive planning, provenance independence, and replay/reproducibility.

## Canonical constraints

- Benchmark harness != real-world superiority claim.
- Synthetic reference suite MUST be labeled synthetic.
- Every compared variant MUST cover the same case IDs.
- Unknown metric != zero.
- Raw source mentions != independent source roots.
- Benchmark report MUST identify baseline and metric direction.
- Benchmark input/report identities MUST be content-addressed and input-order independent.
- Replaying the same spec + dataset MUST reproduce the same report identity.
- No Provider, Planner, Policy, Evidence, Routing, Stopping, Experience, or crawler runtime semantics are modified.
- No live API credentials or network calls are required for the canonical v0.8 reference suite.
